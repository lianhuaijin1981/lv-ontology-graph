本轮核心变更
--------------
1. 彻底弃用 G6 Canvas/WebGL 渲染（闪烁/过曝/右键无效的根源）
   → 回退到纯 D3.js SVG DOM 渲染，零发光、零模糊、零动画抖动

2. 主流程可视化完全重构
   → 核心链路节点：金色描边 (#FBBF24) + 28px 大尺寸 + 默认显示黄色文字标签
   → 核心链路边：4px 金色粗线 + 独立金色箭头 marker (arrow-gold)
   → 节点尺寸三级：T1=28px / T2=20px / T3=14px
   → 主流程一眼可读：海外品牌商A → 外贸大货订单 → 海运订舱服务、鞋款设计方案 → 裁断车间 → 贴底工艺 → 高温定型等

3. 右键菜单 —— 双层阻止
   → SVG 节点元素：event.preventDefault() + event.stopPropagation()
   → 外层容器 div：onContextMenu 兜底拦截
   → 右键呼出实体详情面板（ObjectExplorer），不再出现浏览器默认菜单

4. 力导向布局参数优化
   → link distance: 130, strength: 0.6
   → charge: -1400
   → collide: radius + 30
   → 双向中心力 (x/y strength: 0.08)
   → alphaDecay: 0.04 → 400ms 快速稳定

5. 其他交互优化
   → 标签默认隐藏（核心链路除外），悬停显示 Tooltip（类型·业务板块）
   → 左键 toggle 选中高亮邻居，空白点击取消
   → 箭头 refX 调整到 38~40px，避免与节点重叠
